# Diagram generator

The SVG diagrams in each subject repo (`src/diagrams/*.svg`) are generated by these scripts.
Each subject file (`bio.py`, `chem.py`, `maths.py`) defines a dict `D` of
`name: (svg, unit file, summary heading, caption)`.

To regenerate one subject and attach the diagrams to its topics:

```bash
cd ~/Documents/Projects/alevel-hub/tools/diagrams
python3 apply.py bio ~/Documents/Projects/alevel-biology/src
cd ~/Documents/Projects/alevel-biology/src
python3 build.py
```

`apply.py` writes `src/diagrams/<name>.svg` and adds `fig:` and `cap:` to the matching
summary section in `content/uNN.yaml`. Colours come from classes styled by the hub
template (`.fig .ac` accent, `.gl` gold, `.ln` text colour, etc.), so the diagrams follow
the light/dark theme and each section's accent colour.
